# Luck 运行环境约定

本包只依赖 Go 标准库，集中定义与 Luck.Framework 一致的进程环境变量契约，后续可独立迁移到共享 SDK。

- `LUCKENV`：当前运行环境。
- `SERVICEUK`：当前服务唯一标识。
- 两项均由部署方提供，缺失、空字符串或仅含空白时启动失败；读取时去除首尾空白，保留大小写。
- `Load` 返回启动时的不可变约定值；不读取配置文件，不提供默认值，也不决定业务组件的 Redis 命名规则。

权限中心使用 `LUCKENV` 生成 Redis 前缀，使用 `SERVICEUK` 标识自身管理服务。其他服务若使用该契约，仍需各自明确这些值如何影响其资源命名。
